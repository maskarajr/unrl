# Changelog

## 0.1.0 — 2026-08-18

First preview of `@maskarajr/unrl`.

- Forward resolve: ENS, SNS, Base Names, Unstoppable (TLD → module)
- Reverse: ENS + Base L2 primary + Unstoppable profile (comma-joined names)
- Public result: `{ address, resolver }` forward, `{ name, resolver }` reverse
- Optional `udApiKey`, RPC URLs, cache TTL
